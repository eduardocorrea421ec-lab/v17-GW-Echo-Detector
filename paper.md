# Summary
Systematic search for post-merger echoes and 4 types of GR deviations in 128 BBH events from GWTC-3 with SNR >=15 using open GWOSC data. Zero detections, false positive 0.00%, 95% upper limit <0.78%.

# Statement of need
Open pipelines for echo searches using public GWOSC data are scarce. Many claims since 2017 lack open code. V17 provides a fully open workflow for Google Colab.

# Results
128 events analyzed, 0 detections, <0.78% at 95% CI. Most downloaded preprint with 37 views / 14 downloads.
